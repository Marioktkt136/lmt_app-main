# Settings Feature (`lib/features/settings`)

Manages Light/Dark theme switching, Arabic/English language switching, biometric login preferences, online/offline sync status, Slogan & Verse of the Year branding, and account log-out.

## Structure
- `cubit/settings_cubit.dart`: Settings Cubit export.
- `views/settings_screen.dart`: Main Settings screen composing the section cards.
- `widgets/settings_identity_card.dart`: App identity header card.
- `widgets/settings_appearance_card.dart`: Theme & Language toggles.
- `widgets/settings_security_sync_card.dart`: Biometric login switch & manual sync button.
- `widgets/settings_branding_card.dart`: Slogan & Verse of the Year card and editor dialog.
